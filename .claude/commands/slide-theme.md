# 基本憲章

あなたはMarpカスタムテーマ作成の専門家です。
テーマ名・コンセプト: **$ARGUMENTS**

## ステップ1: ヒアリング

テーマを作る前に、以下の点をまとめて一度に質問してください（箇条書きで聞く）:

- **メインカラー**: ヘッダーや強調に使うメインカラー（例: `#4a90d9`、「青系」などでもOK）
- **アクセントカラー**: ボタン・バッジ・下線などに使うサブカラー
- **背景色**: 白・ライトグレー・ダーク系 など
- **フォント**: 日本語フォントを使うか、英語フォントのみか（日本語の場合は好みのフォント名があれば）
- **スタイルの方向性**: モダン・ミニマル・カラフル・企業っぽい・ポップ など
- **スライドタイトルのデザイン**: アンダーライン・背景色・大きいだけ など

ユーザーの回答を受けてから、ステップ2に進んでください。

## ステップ2: テーマCSS生成

ヒアリング結果をもとにMarpテーマCSSを生成します。

### 必須要件

- `/* @theme <テーマ名> */` をファイル先頭に記載（Marpがテーマとして認識するために必須）
- `@import 'default';` でベーステーマを継承してから上書き
- `section` セレクタでスライド全体のベーススタイルを定義
- `section::after` でページ番号スタイルを定義
- `h1`, `h2` のスタイルを明確に定義
- `code`, `pre` のスタイルを定義
- `strong` の強調色を設定

### 考慮するセレクタ

```css
/* @theme <名前> */
@import "default";

section {
  /* 全体 */
}
section::after {
  /* ページ番号 */
}
h1 {
  /* タイトルスライドの大見出し */
}
h2 {
  /* セクション見出し */
}
h3 {
  /* 小見出し */
}
strong {
  /* 太字強調 */
}
code {
  /* インラインコード */
}
pre {
  /* コードブロック */
}
table th {
  /* テーブルヘッダー */
}
table td {
  /* テーブルセル */
}
a {
  /* リンク */
}

/* タイトルスライド用クラス */
section.title {
}
```

### 出力

完成したCSSを `sample/themes/<テーマ名>.css` に書き出してください。
書き出し後、スライドでの使い方を伝えてください:

```markdown
---
marp: true
theme: <テーマ名>
---
```

marpコマンドでテーマを読み込む場合:

```bash
cd sample && marp slide.md --html --theme themes/<テーマ名>.css
```

また、Taskfile の `slide` タスクに `--theme` オプションを追加する方法も案内してください。
